## v8 — The Hospitality AI Implementation Consultancy

### Positioning (one line)

> **AI implementation for Australian restaurants. We help you pick and install the right tools — Sophiie, Sadie, Slang.ai, SevenRooms Voice, OpenTable Concierge — so you stop guessing which one to buy and start using one that works.**

### The buyer

Mid-tier Sydney restaurants, 30–150 covers, A$1M–8M revenue, owner-operated or GM-led. Currently either drowning in inbound calls (no AI tool yet) or paying for Sophiie/Sadie/Slang but underutilising it. Low-to-medium tech literacy. Buying motivation = time recovery, not cost savings.

### Three-product ladder

**1. AI Diagnostic Audit — A$1,500 one-shot**
- 60–90 min on-site audit + 1-page roadmap delivered within 5 days
- Map current tech stack, identify 3-5 highest-ROI AI opportunities, recommend specific tools with ROI estimates
- 50% credits against Implementation if booked within 60 days
- Time cost: ~8 hours per audit. Margin: ~90%.

**2. AI Implementation — A$3,500–7,500 project**
- 2–3 week project
- Install + configure recommended AI tool (Sophiie / Sadie / Slang.ai / SevenRooms / Numa / Goodcall), integrate with their POS + booking + calendar, train staff, 30-day tuning window
- Three tiers: single-tool (A$3,500), dual-tool (A$5,000), full-stack rebuild (A$7,500)
- Time cost: 25–40 hours per implementation. Margin: ~70–80%.

**3. Monthly Optimisation Retainer — A$500–1,500/mo recurring**
- Monthly 30-min tuning call + ongoing vendor liaison
- Performance review + tweaks, add new AI tools as shipped, handle vendor support tickets, quarterly business reviews
- Three tiers: light A$500, standard A$750, full-stack A$1,500
- Time cost: 2–4 hrs/client/month. Margin: ~90%.
