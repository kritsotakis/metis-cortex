## The three-product ladder

### 1. AI Diagnostic Audit — A$1,500 one-shot

- **Format:** 60–90 min on-site audit + 1-page written roadmap delivered within 5 days
- **Scope:** Map current tech stack (POS, booking, marketing, voice). Identify 3-5 highest-ROI AI deployment opportunities. Recommend specific tools with ROI estimates.
- **Deliverable:** 1-page roadmap, 30-min walkthrough call, written tool recommendations + setup cost estimates
- **Conversion mechanic:** 50% of audit fee credits against Implementation if booked within 60 days
- **Time cost to you:** ~8 hours per audit (4 on-site + 4 writing)
- **Margin:** ~90% (your time is the cost)

### 2. AI Implementation — A$3,500–7,500 project

- **Format:** 2–3 week project
- **Scope:** Install + configure recommended AI tool (Sophiie / Sadie / Slang.ai / SevenRooms / Numa / Goodcall). Integrate with their POS, booking platform, calendar. Train staff. 30-day tuning window.
- **Tier pricing:**
  - A$3,500 — single-tool install (e.g. just Sophiie)
  - A$5,000 — dual-tool install (e.g. Sadie + a CRM integration)
  - A$7,500 — full-stack rebuild (multiple tools, POS migration, staff training program)
- **Time cost to you:** 25–40 hours per implementation
- **Margin:** ~70–80%

### 3. Monthly Optimisation Retainer — A$500–1,500/mo recurring

- **Format:** Monthly 30-min tuning call + ongoing vendor liaison
- **Scope:** Monthly performance review + tweaks. Add new AI tools as they ship. Handle vendor support tickets on their behalf. Quarterly business review with KPIs.
- **Tier pricing:**
  - A$500/mo — single-tool monitoring (light touch)
  - A$750/mo — dual-tool optimisation (standard)
  - A$1,500/mo — full-stack management (multi-location or complex)
- **Time cost to you:** 2–4 hours per client per month
- **Margin:** ~90%

## Risks and what could break

1. **Vendor consolidation** — if Sophiie buys Sadie, or Square buys NowBookIt, the tool-comparison advisory thins out. Mitigation: lock affiliate agreements early, keep relationships across multiple vendors.
2. **Restaurant economy downturn** — hospitality is margin-thin. A recession kills your buyer's appetite for tools. Mitigation: target restaurants doing >A$2M revenue (less downturn-sensitive).
3. **Solo-operator cap** — at ~25-30 retainer clients you're maxed. Path forward: hire an installer (Path C v3 original spec called for this at Client #10).
4. **You burn out on consulting** — this isn't subscription SaaS. Each client = real time. If you genuinely want pure low-touch revenue, this isn't it — the data feed Model 2 is closer.
