## Reading this report

1. **Look at the high-occurrence facts first** — the values that appear in many documents. Those are the load-bearing claims of the matter. They MUST be consistent.

2. **Flag near-duplicates** — `$327,016` vs `$327,000` vs `$327k` are not the same to a court even if they're 'roughly the same'. Pick the precise number and use it everywhere.

3. **Gap analysis** — facts that appear in only one doc but logically should appear in others (e.g. Peter's CRN appearing in cover letters but not the affidavit). The report doesn't auto-detect these; you scan for them.

4. **Re-run after every material edit** — pattern is deterministic, so the only changes between runs are real changes in the matter. A 5-second sanity check before any filing.
